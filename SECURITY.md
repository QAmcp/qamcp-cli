# Security

## Reporting a problem

If you find a security problem in QAmcp, please report it privately: open the **Security** tab of this repository and click **Report a vulnerability**. Please don't open a public issue for it.

We'll reply within 7 days and tell you what we're doing about it.

## Supported versions

Only the newest version on npm (`qamcp-cli`) gets security fixes.

## About the test servers

The servers in `test/` are broken on purpose so QAmcp has something to catch. The keys and passwords in them are fake and made up at run time; none of them work anywhere.
